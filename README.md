# GAUS_app: Решение СЛАУ методом Гаусса с использованием Eigen

Программа для решения систем линейных алгебраических уравнений (СЛАУ) вида `Ax = b` методом Гаусса. Использует библиотеку Eigen для эффективных операций с матрицами и векторами, включая потенциальное использование аппаратной векторизации через BLAS/LAPACK.

## Основные Возможности

* **Решение СЛАУ:** Чтение расширенной матрицы `[A|b]` из CSV файла и вывод вектора решения `x` в CSV файл.
* **Генерация Систем:** Создание тестовых СЛАУ заданного размера с использованием воспроизводимого генератора псевдослучайных чисел (ГПСЧ) - Вихря Мерсенна (`std::mt19937`). Сгенерированная матрица сохраняется в CSV.
* **Eigen и BLAS/LAPACK:** Операции линейной алгебры выполняются с помощью Eigen. Проект по умолчанию собирается с поддержкой OpenBLAS и LAPACKE для возможного ускорения вычислений на больших матрицах (требует установки соответствующих библиотек).
* **CSV Ввод/Вывод:** Работа с данными осуществляется через файлы формата CSV.
* **Тестирование:** Включает модульные тесты на базе Google Test для проверки корректности компонентов.
* **Сборка:** Используется стандартная система сборки `make`.

## Зависимости и Установка

### Требования к системе:

* Компилятор C++ с поддержкой стандарта C++17 (например, g++)
* Система сборки `make`
* Git (для клонирования и работы с сабмодулями)

### Внешние библиотеки (Подключаются как сабмодули Git):

* **Eigen:** Высокопроизводительная библиотека C++ для линейной алгебры.
* **lazycsv:** Легковесная библиотека для чтения CSV файлов.

Сабмодули подключаются автоматически при клонировании с флагом `--recursive` или вручную после клонирования:
```bash
git submodule update --init --recursive
```

### Системные зависимости (Пример для Debian/Ubuntu):

Для сборки проекта и запуска тестов могут потребоваться следующие пакеты:

```bash
sudo apt-get update
# Основные инструменты сборки
sudo apt-get install build-essential make g++ git
# Зависимости для тестов (Google Test)
sudo apt-get install libgtest-dev
# Зависимости для ускорения Eigen (опционально, но включено по умолчанию)
sudo apt-get install libopenblas-dev liblapacke-dev
```

**Важно:** Пакет `libgtest-dev` в Debian/Ubuntu обычно устанавливает только исходные коды Google Test. Их нужно скомпилировать вручную один раз после установки:
```bash
cd /usr/src/googletest
sudo cmake .
sudo make
sudo cp lib/*.a /usr/lib # Копируем статические библиотеки в системный каталог
cd - # Вернуться в предыдущий каталог
```

## Сборка Проекта

1.  **Клонировать репозиторий** (включая сабмодули):
    ```bash
    git clone --recursive <URL_вашего_репозитория> GAUS_app
    cd GAUS_app
    ```
    (Если клонировали без `--recursive`, выполните `git submodule update --init --recursive`)

2.  **Установить системные зависимости** (см. раздел выше).

3.  **Собрать проект** с помощью `make`:
    ```bash
    make
    ```
    По умолчанию сборка происходит с поддержкой BLAS/LAPACK. Исполняемый файл будет называться `GAUS_app`.

## Использование Программы

Программа имеет два режима работы, определяемых первым аргументом командной строки.

### 1. Решение из Файла (`--file`)

Этот режим читает расширенную матрицу `[A|b]` из входного CSV файла, решает систему `Ax=b` и записывает вектор решения `x` в выходной CSV файл.

**Команда:**
```bash
./GAUS_app --file <input_matrix.csv> <output_solution.csv>
```

* **`<input_matrix.csv>`:**
    * Путь к входному файлу CSV.
    * **Формат:** Каждая строка представляет строку расширенной матрицы `[A|b]`. Значения разделяются запятыми. Количество столбцов должно быть `N+1` для системы `N x N`.
    * **Важно:** Парсер настроен НЕ пропускать первую строку как заголовок (`has_header<false>`). Убедитесь, что в файле нет строки заголовка, или раскомментируйте `parser.skip_header()` в `src/csv_handler.cpp`.
* **`<output_solution.csv>`:**
    * Путь к файлу, куда будет сохранен результат.
    * **Формат:** Столбец значений вектора решения `x`, по одному значению на строку. Первая строка содержит заголовок "Solution".

### 2. Генерация Системы (`--generate`)

Этот режим генерирует случайную расширенную матрицу `[A|b]` заданного размера и сохраняет ее в CSV файл для последующего анализа или использования в режиме `--file`. **Решение системы в этом режиме не производится.**

**Команда:**
```bash
./GAUS_app --generate <size> <seed> <output_matrix.csv> [min_val] [max_val]
```

* **`<size>`:** Размер системы (количество уравнений/неизвестных N). Матрица будет N x (N+1).
* **`<seed>`:** Целое число для инициализации генератора псевдослучайных чисел (ГПСЧ `std::mt19937`). Использование одного и того же seed гарантирует генерацию одинаковых матриц.
* **`<output_matrix.csv>`:**
    * Путь к файлу для сохранения сгенерированной расширенной матрицы.
    * **Формат:** Стандартный CSV (значения через запятую). **Первая строка файла будет пустой** (для совместимости с `skip_header` при последующем чтении).
* **`[min_val]` (необязательно):** Минимальное значение для генерируемых элементов матрицы (по умолчанию -10.0).
* **`[max_val]` (необязательно):** Максимальное значение для генерируемых элементов матрицы (по умолчанию 10.0).

## Тестирование

Для запуска встроенных модульных тестов (написанных с использованием Google Test) выполните:
```bash
make test
```

## Очистка

* Удалить объектные файлы (`*.o`):
    ```bash
    make clean
    ```
* Удалить объектные файлы, исполняемые файлы и библиотеку:
    ```bash
    make cleanall
    ```
